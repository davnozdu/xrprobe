# xrprobe

Диагностический пробник для XREAL One Pro (VID `0x3318` / PID `0x0436`) и камеры XREAL Eye.

Цель — выяснить, как активируется камера Eye, чтобы использовать очки как «умные очки»
без вывода изображения: звук, микрофон и камера.

## Что делает

Только чтение. Ничего в очки не пишется без явного флага.

- `--info` — информация о HID-устройствах (`HIDIOCGRAWINFO`, report descriptor) и USB-топология
- `--syms <path.so>` — `dlopen` библиотеки и проверка, какие символы `NRBSP*` резолвятся
- `--call <path.so>` — попытка вызвать `NRBSPGetCameraStatus` с несколькими вариантами ABI,
  каждый в отдельном дочернем процессе, чтобы падение не убило пробник

## Чего здесь нет

**Проприетарные библиотеки XREAL в репозиторий не входят.** `libnr_glasses_api.so`,
`libota-lib.so` и прочее остаются у владельца устройства и подкладываются на телефон
локально. Код использует `dlopen`, поэтому при сборке они не нужны.

## Сборка

GitHub Actions собирает статический ARM64-бинарник (Android NDK, API 29).
Готовый файл — в артефактах сборки.

## Запуск

    adb push xrprobe /data/local/tmp/ && adb shell su -c "chmod 755 /data/local/tmp/xrprobe && /data/local/tmp/xrprobe --info"
